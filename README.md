# invest-management · Капитал

My own investment management system (based on ChatGPT).

Небольшое приложение на Python для личного учёта брокерских счетов, недвижимости и криптовалют. Русский адаптивный интерфейс, SQLite, без облака, внешних шрифтов, аналитики и сторонних Python-зависимостей. Python 3.10+ (в Ubuntu 24.04 подходит системный Python).

## Запуск

Клонируйте репозиторий и запустите приложение:

```bash
git clone https://github.com/avkarcr/invest-management.git
cd invest-management
python3 app.py
```

Если скачали ZIP, распакуйте его, откройте терминал в папке с `app.py` и выполните:

```bash
python3 app.py
```

Откроется браузер: http://127.0.0.1:8765. Если браузер не открылся, введите адрес вручную. Для остановки нажмите Ctrl+C в терминале. Данные сохраняются между запусками.

Дополнительные варианты:

```bash
bash start.sh
python3 app.py --port 8766
python3 app.py --no-browser
python3 app.py --db /полный/путь/к/моей-базе.sqlite3
```

Интернет для работы не нужен. При первом запуске создаётся пустая база, без вымышленных инвестиций. Программа слушает только 127.0.0.1 и рассчитана на одного пользователя своего компьютера.

## Первое заполнение

1. В «Курсы и данные» добавьте необходимые валюты. Курс — число рублей за 1 единицу валюты. RUB уже добавлен. Курсы и дата их актуальности вводятся вручную. USD и USDT — отдельные валюты.
2. Добавьте активы. Можно вести счёт целиком либо отдельные позиции и денежный остаток. Не включайте одновременно общий баланс и входящие в него позиции: это удвоит капитал.
3. Для актива укажите название, площадку/счёт, стоимость покупки, текущую оценку и остаток долга. Все суммы относятся ко всему активу и выражены в одной выбранной валюте. Для недвижимости указывайте стоимость вашей доли и относящийся к ней долг. Для криптовалют можно использовать оценку в USDT или вручную добавить курс BTC и других валют.
4. Записывайте аренду, дивиденды, купоны, комиссии и прочие доходы/расходы. Укажите фактический курс на дату операции. Эти операции не обновляют баланс актива автоматически.
5. После обновления оценок сохраните снимок в «История капитала». Один снимок в день; повторное сохранение заменяет его после подтверждения.
6. Регулярно скачивайте резервную копию в «Курсы и данные».

## Что означают показатели

- Стоимость активов: сумма текущих оценок, пересчитанных по текущим ручным курсам.
- Чистый капитал: стоимость активов минус долги.
- Изменение оценки: текущая стоимость минус стоимость покупки, обе суммы пересчитаны по текущему курсу. Это не реализованная прибыль, не полная инвестиционная доходность и не валютная прибыль относительно курса покупки.
- Структура и суммы по площадкам показываются по полной стоимости, до вычета долгов.
- Доходы/расходы показываются за всё время по сохранённому курсу каждой операции. Обновление курса валюты их не меняет.
- История содержит зафиксированные агрегированные показатели. Снимки не хранят состав портфеля и не меняются после редактирования активов или курсов.

В этой версии нет автоматических котировок, подключения API брокеров и бирж, налоговой отчётности, учёта лотов, сделок, пополнений/выводов, реализованной прибыли, XIRR/TWR, импорта банковских отчётов и фильтра денежных потоков по периоду. Данные нужно актуализировать вручную. Денежные расчёты сервера используют Decimal; интерфейс отображает суммы с округлением до двух знаков.

## Экспорт и резервное копирование

- **CSV** — текущие активы, UTF-8 с BOM; открывается в LibreOffice. Строки, похожие на формулы, экранируются апострофом.
- **JSON** — все записи и текущие сводные показатели; это переносимый экспорт, автоматического импорта через интерфейс нет.
- **SQL** — полная резервная копия всех таблиц из согласованного снимка SQLite. Храните копию отдельно от компьютера.

База: `data/capital.sqlite3` рядом с `app.py`. После остановки приложения её можно копировать обычным файловым менеджером и восстановить заменой файла. Не удаляйте старую базу до проверки копии.

Для восстановления скачанного SQL используйте прилагаемый скрипт. Он создаёт **новый** файл и отказывается перезаписывать существующий:

```bash
python3 restore.py ~/Downloads/capital-backup.sql data/restored.sqlite3
python3 app.py --db data/restored.sqlite3
```

Используйте только собственные доверенные SQL-копии. Резервные копии содержат финансовые данные. База и экспорт не зашифрованы; защиту хранения обеспечивает ваш компьютер/шифрование диска. Пароли, API-ключи и seed-фразы для работы не нужны.

## Разработка и GitHub

```bash
python3 -m unittest discover -s tests -v
```

Файлы: `app.py` — HTTP API, проверка данных и SQLite; `static/` — интерфейс; `tests/` — тесты расчётов, сохранения, конвертации, копий и защиты запросов. Для изменения интерфейса не нужен Node.js или сборщик.

`.gitignore` исключает рабочую базу и обычные экспорты. Перед коммитом проверяйте, что другие финансовые копии также не попали в Git. Репозиторий: https://github.com/avkarcr/invest-management.
